# KoWOPTV Guide

A TV-guide style schedule for KoWOPTV, in the spirit of the classic cable
preview channels and print TV listings.

The page is a single static `index.html`. The schedule is published
automatically to the `data` branch and loaded by the page in your browser.

Keyboard: ↑ ↓ channels · ← → programs · PgUp/PgDn page · N now ·
A auto-scroll · T change look · F fullscreen · S settings
